# SitePulse WP Client

Expose site uptime, software update information, and security reports through the WordPress REST API for a monitoring dashboard.

## Installation and use

1. Place the `sitepulsewp-client` folder in `wp-content/plugins/`.
2. Activate SitePulse WP Client in the WordPress Plugins screen.

The `spwc/v1` routes for uptime, updates, and security reports permit unauthenticated requests. Account for that access before enabling the client on a live site.
